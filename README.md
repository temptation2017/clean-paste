# clean-paste

粘贴文本**本地**检出并清除零宽字符、BOM、双向控制符、软连字符等不可见 Unicode。纯前端，不上传。

适合：把日志 / 代码 / 工单内容贴进聊天、Issue、编辑器之前，先扫一眼有没有藏着的隐形字符（也会影响 git diff、构建、甚至 Trojan Source / 提示词注入类手法）。

## 在线演示

https://temptation2017.github.io/clean-paste/

（若页面尚未生效，用下方「本地打开」。）

## 本地打开

无需构建、无需 npm、无需 CDN：

```bash
# 直接双击，或：
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows

# 也可用任意静态服务器
python3 -m http.server 8080
```

打开后整页可离线使用（`file://` 即可）。

## 怎么用

1. 在大文本框粘贴或输入内容（输入会自动扫描，带短防抖）。
2. 查看：可疑字符总数、按码点汇总表（码点 / 中文标签 / 次数 / 上下文样例）、可视化预览（不可见字符标成 `⟦ZWSP⟧` 等，**不改动**原文缓冲区）。
3. 点 **清除不可见字符** → 下方得到清理结果。
4. 点 **一键复制清理结果**。
5. **填入示例** 可载入一段含 ZWSP / BOM / 软连字符 / 双向覆盖 / NBSP 等的虚构样本。
6. 可选勾选：**同时规范化非常规空格 → 普通空格**（NBSP、窄 NBSP、表意空格等）。

## 检测范围

| 类别 | 码点 | 说明 |
|------|------|------|
| BOM | U+FEFF | 字节顺序标记 / ZWNBSP |
| 零宽 | U+200B ZWSP、U+200C ZWNJ、U+200D ZWJ、U+2060 WJ | 常见于复制网页 / Word |
| 双向控制 | U+202A–U+202E、U+2066–U+2069 | 含 RLO 等，与 Trojan Source 相关 |
| 软连字符 | U+00AD | Soft Hyphen |
| 方向标记等 | U+200E LRM、U+200F RLM、U+061C ALM 等 | 格式类 |
| 其他常见 Cf | 变体选择符、Tag、部分填充/连接符等 | 合理子集 |
| 替换字符 | U+FFFD | 作为警告标出 |
| 非常规空格（可选规范化） | U+00A0 NBSP、U+202F、U+3000 等 | 默认只标出；勾选后替换为 U+0020 |

普通空格、换行、制表符**默认保留**。

逻辑在 `clean.js`（浏览器与 Node 均可加载），页面逻辑在 `app.js`。

## 隐私

**全部在浏览器本地完成，不会上传任何文本。** UI 与本说明均标明此点。可断网使用。

## 限制

- 不做完整 Unicode 通用类别数据库覆盖；聚焦工程里常见「隐形捣乱」子集。
- 组合用变音符号（Mn）默认不剥，避免误伤正常多语言文本。
- `file://` 下剪贴板 API 在部分浏览器可能受限，失败时可手动全选清理结果。
